# miniOrange Cursor plugins

## Plugins

- **[mcp-server-for-wordpress](plugins/mcp-server-for-wordpress)**: connects
  Cursor to a WordPress site through the miniOrange MCP gateway
  (`https://gateway.miniorange.ai/v2/mcp`), exposing WordPress Abilities API
  actions as tools.

- **[mcp-server-magento](plugins/mcp-server-magento)**: connects
  Cursor to a Magento 2 / Adobe Commerce store through the miniOrange MCP
  gateway (`https://magento.miniorange.com/mcp`), exposing purpose-built
  MCP tools for catalog, inventory, orders, and customers.
